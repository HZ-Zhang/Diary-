# Diary-
一款简洁轻量的日记软件，专注纯粹记录日常心情与生活碎片。支持文字随笔、时间线浏览，本地存储保障你的日记隐私，数据留存于本机不上传云端。界面干净无多余广告，上手简单，可快速新建、查阅、编辑日记条目。  项目开源，持续迭代优化，欢迎提交 Issue 反馈 bug 或提出新功能想法，也欢迎 Star 支持。适合想安静记录生活、重视个人隐私的使用者。
